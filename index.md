# Tiedepalsta Backup

Tiedepalsta Backup is a privately operated backup utility for the Tiedepalsta.fi discussion forum.

The application uses Google Drive through rclone to store, retrieve, and manage database backups and uploaded forum files.

It is intended exclusively for use by the forum administrator and is not available as a public service.

For privacy information, see the [Privacy Policy](privacy.html).
